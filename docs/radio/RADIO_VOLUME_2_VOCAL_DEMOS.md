# World Fracture Radio — Volume 2: Vocal Demo Songs

Four **original, 132-second radio mixes** are bundled and selected by the four existing stations. Each contains newly written English lyrics (Island Relay uses light Jamaican patois), instrumental arrangement and **synthetic spoken/chant-like vocals produced with offline speech synthesis**. These are demo vocal mixes, **not natural human singing or commercial-quality vocal performances**.

Tracks:
- Block Signal — **After the Fracture** (92 BPM, hip-hop)
- Rust Riot — **Burn the Horizon** (132 BPM, rock)
- Neon Frequency — **Electric Tomorrow** (126 BPM, house)
- Island Relay — **Island Signal** (100 BPM, dancehall/reggae)

The existing radio function now loads the vocal-mix Ogg recording for each station. Audio routes through the music bus so music volume and external-music muting apply; the previous instrumental tracks remain in the package. The mixes are 132 seconds each and loop at the end.

**Production limitations:** The vocal performances are synthetic speech over music, not fully sung recordings. The backing tracks use repeating patterns. There is no multi-song rotation or DJ interstitial yet. In-game playback and the production build have not been verified.
