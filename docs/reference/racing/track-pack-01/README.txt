WORLD FRACTURE — 8 ACTUAL RACE TRACK PROTOTYPES

FILES
- 8 .glb models: real 3D meshes with roads, shoulders, dashed centerlines, checkpoint posts and start/finish.
- tracks.json: sampled world-space centerlines and checkpoints.
- PLAYABLE_RACING_DEMO.html: self-contained 2D browser driving proof-of-concept, no installation required.

OPEN THE PLAYABLE DEMO
Double-click PLAYABLE_RACING_DEMO.html in a modern browser.
Select a track; drive with W/A/S/D or arrow keys; Space handbrake; R restart.
This is a top-down arcade prototype, not the full World Fracture 3D game.

OPEN THE 3D TRACKS
Import individual GLB files in Blender or Three.js GLTFLoader.
Distances are full-scale in meters. Long tracks can be very large in Blender's viewport.

NOT YET IMPLEMENTED
World terrain fitting, barriers/collision, scenery, buildings, AI racing opponents,
traffic, police, timing validation, economy/rewards, multiplayer, persistence,
3D playable vehicle integration, and full game integration.
The browser demo uses a simplified car model and proximity-based gates;
it is not production-grade racing physics or anti-cheat lap validation.
