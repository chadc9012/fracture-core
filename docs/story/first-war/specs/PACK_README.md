# WORLD FRACTURE — FIRST WAR CHARACTER PACK
This package consolidates the five legendary character visual references and per-character 3D production briefs.

## Important status distinction
The included images are visual concept references. The Markdown briefs define the target production requirements. This package does **not** contain finished 3D geometry, UV-mapped meshes, rigged skeletons, facial rigs, animation clips, or FBX/GLB model exports. Those assets still need to be produced in a 3D modeling/character pipeline.

## Characters
1. Ilyra Sen — The Voice of the Concord
2. Vael Turog — The Severant
3. Auren Thale — The First Cartographer
4. The Veiled Sovereign — Founder of the Unbound
5. The Echo Before Names — The First Consciousness

## Shared production baseline
- Realistic GTA V-style human character rendering with restrained supernatural effects.
- Hero-quality PBR materials, clean UVs, modular components and gameplay LODs.
- Humanoid skeleton and facial rig; character-specific secondary motion.
- Separate VFX assets, not baked into base geometry.
- FBX engine delivery and GLB review delivery.
- Character-specific animation lists are documented in each brief.
